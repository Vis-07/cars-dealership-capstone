# Cars Dealership Capstone Project

## Project Name
Cars Dealership Web Application

## Description
A full-stack web application for a car dealership business that allows users to view dealership locations, explore dealer details, register and log in, and submit reviews.

## Technologies
- Frontend: React, HTML, CSS, JavaScript
- Backend: Django and Python
- Database: SQLite
- Deployment and CI/CD: Docker, Kubernetes, IBM Cloud Code Engine, and GitHub Actions

## Features
- View dealership locations and details
- Filter dealers by state
- User registration and login
- Submit and view dealer reviews
- Sentiment analysis of customer reviews
